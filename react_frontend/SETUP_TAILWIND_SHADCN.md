# Tailwind + shadcn/ui Setup

- Install dependencies: npm i
- Start dev: npm run dev

Included:
- Tailwind config with project colors (primary #2563eb, secondary #64748b, accent #d97706)
- Base CSS variables in src/index.css
- shadcn/ui primitives in src/components/ui

Note: Module declaration shims are provided in src/types/external-shims.d.ts for initial typechecking. They will be superseded once dependencies are installed.
